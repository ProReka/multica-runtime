# Brand and cover art

This file holds the visual direction for the project and copy-paste prompts for
generating cover art. Generated images are not committed by default; add the
final files under `docs/assets/` and reference them from the README or docs.

## Palette

| Token | Hex | Use |
|---|---|---|
| Ink | `#070B14` | background, dark surfaces |
| Slate | `#101827` | panels, container body |
| Cyan | `#22D3EE` | primary accent, runtime/agent links |
| Violet | `#A78BFA` | secondary accent, model/agent variety |
| Amber | `#F59E0B` | warm accent, toolchain layers |
| Mist | `#E5E7EB` | primary text |
| Muted | `#94A3B8` | secondary text |

The visual idea is **one runtime, many agents**: a single solid container with
several glowing paths leaving it, not a collage of product logos. Keep it dark,
precise, and uncrowded. Avoid the Docker whale, AI vendor logos, and readable
text generated by the model — typography goes on afterwards in Figma, Affinity,
or Canva.

## Prompt A — Container constellation (main cover)

Best for the README hero, docs landing page, and GitHub social preview.

```text
Premium developer-tool cover art, wide 16:9 composition, dark cinematic 3D
render. A single matte-black server container monolith with softly glowing seams
floats right of center above a deep navy void. Its open front reveals five
stacked translucent toolchain layers — teal glass, amber glass, violet glass,
cool blue glass, and a warm coral layer — each etched with faint abstract
terminal marks, no readable text. From the top of the monolith, six thin
fiber-optic filaments arc outward to small luminous agent orbs, each a different
accent color, suggesting multiple AI coding agents sharing one runtime. A subtle
perspective grid and fine particle haze sit on the floor. Volumetric rim light,
crisp reflections, shallow depth of field, clean negative space in the left third
for a title. Palette: near-black #070B14, cyan #22D3EE, violet #A78BFA, amber
#F59E0B, cool white highlights. High-end developer brand, octane render, isometric
3D, matte metal and glass, sharp edges, minimal, no clutter, 8k, professional.
```

Aspect ratio: **16:9** (generate at 1920×1080 or larger).

## Prompt B — Terminal monolith (minimal alternate)

Best when the cover needs to sit next to a lot of text without competing.

```text
Minimal editorial technology cover, wide 16:9, deep navy background. A single
floating glass terminal cube, nearly black, with one thin cyan cursor line
glowing inside and a soft amber edge light on the lower right. Beneath it, five
thin translucent horizontal slabs suggest different language toolchains, spaced
like a stack of unlabeled layers. A very subtle dot grid fades into the
background. Lots of empty space on the left for typography, object on the right.
Cinematic softbox lighting, crisp glass refraction, quiet and premium, no
clutter, no text, 8k product render.
```

Aspect ratio: **16:9**.

## Prompt C — Agent swarm (social crop)

Use this when you want something more energetic for a launch post.

```text
Dark futuristic developer artwork, 2:1 social banner composition. A compact
glowing runtime core sits on the right, sending five thin light trails to five
small agent nodes on the left, each node a different color: cyan, violet, amber,
blue, coral. The trails are clean fiber-optic arcs, not chaotic wires. The left
side has deliberate empty space for a headline. Fine grid, soft volumetric fog,
high contrast, premium 3D render, matte black and glass, no text, no logos, no
faces, 8k.
```

Aspect ratio: **2:1** (1280×640 for GitHub's social preview).

## Negative prompt

Use this with any of the prompts above:

```text
text, letters, words, typography, logos, brand marks, Docker whale, vendor logos,
human faces, hands, cluttered circuit board, rainbow gradients, neon cyberpunk
city, floating code snippets, watermark, signature, low resolution, blurry,
oversaturated, busy composition, too many objects
```

## Typography overlay

Add this after generation so the text is crisp and spell-checked:

| Element | Copy | Style |
|---|---|---|
| Kicker | `DOCKER IMAGES FOR AI AGENTS` | 12–14 px, uppercase, letter-spacing 0.18em, cyan |
| Title | `MULTICA RUNTIME` | 64–96 px, Space Grotesk Bold or Geist Bold, white |
| Subtitle | `Claude Code + OpenCode` | 24–32 px, Mist |
| Tagline | `One container. Any stack.` | 18–22 px, Muted |
| Footer | `ghcr.io/proreka/multica-runtime` | 14–16 px, JetBrains Mono, Muted |

Keep the left 40–45% of the image free for this block. Do not center the title
over the object; the asymmetry is what makes the cover look designed.

## Where to use it

- `docs/assets/cover.png` — 1600×900 or 1920×1080, README hero.
- `docs/assets/social-preview.png` — 1280×640, GitHub repository social preview.
- `docs/assets/cover-square.png` — optional 1080×1080 for announcements.

GitHub's social preview is uploaded in **Repository settings → Social preview**,
not from a file in the repository. The docs image can be referenced normally:

```markdown
![Multica Runtime cover](assets/cover.png)
```
